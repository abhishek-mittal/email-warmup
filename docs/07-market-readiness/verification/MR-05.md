## Before

- The Gmail check searched with no mailbox selected, which is a protocol error.
- Every failure (sign-in, timeout, missing seed) was counted as "missing", lowering the sender's result.
- A batch timeout discarded results already gathered.
- A seed deleted mid-test vanished from the denominator.
- `completed_at` was set at insert; pending tests looked finished to the quota count.
- Free and unknown plans got a trial quota. Quota was checked before, not with, the insert.
- No way to add or health-check seeds; the table was empty.

## What changed

- **Per-seed results.** `placement_results` gets one row per selected seed when the test is created. Outcomes: `primary`, `promotions`, `other_inbox`, `spam`, `not_found` (observations) and `smtp_rejected`, `auth_error`, `timeout`, `seed_unavailable`, `error` (no observation).
- **Test status** `queued → running → complete | partial | failed`, with separate created, started and completed times.
- **Percentages** are over observed seeds only. Fewer than three observations is `failed`: no percentages, no score, no effect on the reputation score, and not counted against the allowance.
- **Observation** selects and locks each mailbox before searching; inbox, then spam, then All Mail. Gmail category detection is used only when the server offers Gmail extensions.
- **Resumable.** Each seed result is saved as it arrives; a retry checks only pending seeds. Per-seed timeout 90 seconds, five at a time.
- **Quota** is reserved in a transaction under a per-account lock.
- **Seeds:** operator routes `GET/POST /internal/seeds`, `POST /internal/seeds/check`, `POST /internal/seeds/:id/disable` (need `X-Internal-Secret`). A seed is stored only after it signs in; its password is encrypted and never returned. Daily health check quarantines failing seeds and restores them when they work again. A test needs at least three healthy seeds.
- Spam above 20% queues a diagnosis, once per test.

Migration `0008_placement_observations.sql`: new table and columns; `completed_at` becomes nullable; old unfinished rows are marked failed. Rollback: drop the table and columns, restore the default.
